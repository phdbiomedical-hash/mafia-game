# 🎩 مافيا — لعبة جماعية من الهواتف

كل لاعب يدخل من هاتفه (أندرويد أو آيفون) عبر رابط في المتصفح، دون تثبيت أي تطبيق.

## الأدوار
| الدور | العدد | القدرة |
|---|---|---|
| شيخ المافيا | 1 | يقتل شخصاً كل ليلة (حتى الطبيب) |
| مافيا | 1 | يسكّت شخصاً كل ليلة، فلا يتكلم في النهار التالي |
| طبيب | 1 | يعالج شخصاً كل ليلة فلا يُقتل، ويعالج نفسه مرة واحدة فقط |
| مواطن | الباقي | يكشف المافيا بالتصويت |

شيخ المافيا والمافيا يعرفان بعضهما، ولا أحد غيرهما يعرف هوية أحد.

## سير الجولة
1. **الليل:** كل لاعب يختار من هاتفه بصمت. المواطنون يختارون «من يشكّون فيه» حتى يضغط الجميع ولا ينكشف أحد من حركة يده.
2. **الصباح:** إعلان من قُتل ومن سُكّت، وهل عالجه الطبيب، دون كشف من اختاره الطبيب.
3. **الحوار:** دقيقة ونصف (يستطيع المضيف التخطي أو إضافة 30 ثانية).
4. **التصويت:** كل لاعب يصوّت على اسم واحد. عند التعادل يُعاد التصويت بين المتعادلين، فإن تعادلوا مرة أخرى لا يُستبعد أحد.
5. **التبرير:** نصف دقيقة لصاحب أعلى الأصوات.
6. **القرار الأخير:** يثبّت كل لاعب صوته أو يغيّره. إذا بقي المتهم صاحب أعلى الأصوات يُستبعد وتُكشف هويته.
7. **النهاية:** يفوز المواطنون بإخراج شيخ المافيا والمافيا. تفوز المافيا إذا تساوى عددها مع عدد البقية.

إذا خرج شيخ المافيا تنتقل مهمة القتل إلى المافيا.
الحد الأدنى 5 لاعبين، ويُفضّل 7 أو أكثر (الحد الأقصى 20).

## طريقة التشغيل (اختر واحدة)

### 1) رابط دائم على الإنترنت مجاناً عبر Render (الأسهل للجميع)
1. ارفع هذا المجلد إلى حساب GitHub.
2. ادخل إلى render.com ← **New** ← **Blueprint** واختر المستودع (يقرأ الإعدادات من `render.yaml` تلقائياً).
3. ستحصل على رابط مثل `https://mafia-game-xxxx.onrender.com`، أرسله للاعبين.

> الخطة المجانية «تنام» بعد 15 دقيقة دون استخدام، وأول فتح بعدها قد يستغرق دقيقة تقريباً.

### 2) من حاسوب على نفس شبكة الواي فاي
1. ثبّت Node.js من nodejs.org.
2. افتح الطرفية داخل مجلد اللعبة ونفّذ:
   ```
   npm install
   npm start
   ```
3. سيظهر عنوان مثل `http://192.168.1.5:3000`. افتحه من الهواتف المتصلة بنفس الواي فاي.

### 3) من هاتف أندرويد واحد دون حاسوب (تطبيق Termux)
1. ثبّت **Termux** من F-Droid، ثم نفّذ:
   ```
   pkg install nodejs
   cd mafia
   npm install
   npm start
   ```
2. شغّل «نقطة الاتصال» (Hotspot) في هذا الهاتف، واجعل بقية الهواتف تتصل بها.
3. افتح العنوان الذي يظهر في Termux من بقية الهواتف.

## طريقة اللعب
- شخص واحد يضغط **«إنشاء غرفة جديدة»** فيصبح المضيف.
- الآخرون يمسحون رمز QR أو يفتحون الرابط أو يكتبون رقم الغرفة.
- عندما يدخل الجميع يضغط المضيف **«ابدأ اللعبة»**.
- إذا أُغلقت الشاشة أو انقطع الاتصال يعود اللاعب تلقائياً لنفس مكانه عند فتح الصفحة.
- نصيحة: من قائمة المتصفح اختر «إضافة إلى الشاشة الرئيسية» ليظهر كتطبيق.

## للمطورين
- `game.js`: قواعد اللعبة كاملة، وكلها تُحسب على الخادم حتى لا يستطيع أحد الغش من هاتفه.
- `server.js`: خادم Express + Socket.IO.
- `public/`: واجهة الهاتف (HTML/CSS/JS بدون مكتبات).
- `npm test`: يلعب 200 لعبة عشوائية كاملة للتحقق من القواعد.
